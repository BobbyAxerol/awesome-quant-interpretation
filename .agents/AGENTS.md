# Project Rules for QuantStats Interpretation Bot

## Git Commit Policy
- Always execute `git commit` after making code modifications or additions once verified.
- Write clear, descriptive, and structured commit messages (e.g., following Conventional Commits format `feat: ...`, `fix: ...`, `refactor: ...`).

## Execution & Discussion Policy
- **NEVER execute code modifications, file edits, or system implementations until the user explicitly instructs or approves to proceed** (e.g. "làm đi", "triển khai đi", "duyệt").
- When receiving any task or proposal, ONLY discuss options, outline implementation plans, and ask for clarifying feedback first.
- Wait for explicit user approval before taking action.
