# Copilot Instructions for QuantStats Report Generator

This file provides context and guidelines for AI assistants (like GitHub Copilot) working on this project.

## Project Overview

**QuantStats Report Generator** is a Python automation tool that generates quantitative strategy reports from QuantStats HTML exports.

- **Purpose**: Automate report generation to save time when changing alpha/timeframe/backtest data
- **Main Output**: Professional HTML reports with automated analysis and badges
- **Key Technologies**: Python 3.8+, BeautifulSoup4, Pillow
- **Target Users**: Quantitative traders and strategy developers

## Project Structure

```
build_report.py         # Main script - orchestrator
qs_extract.py          # Extract 12 charts + KPI metrics from QuantStats HTML
qs_analyze.py          # Analyze metrics & generate rule-based comments
template.html          # HTML template with placeholder sections
docs/                  # Documentation files
tests/                 # Unit tests (TBD)
```

## Key Files & Functions

### `build_report.py`
- **Main entry point**: Parse CLI arguments, call extract → analyze → build
- **Handles**: File I/O, template rendering, output generation
- **Args**: `--quantstats`, `--quantstats-test`, `--template`, `--out`, `--sanity-check`

### `qs_extract.py`
- **Main class**: `QuantStatsExtractor`
- **Key constant**: `SLOT_ORDER` - defines order of 12 charts
- **Output**: Dict with charts SVG, metrics, timeframe, eoy_data, drawdown_table
- **Note**: SLOT_ORDER is FIXED - if QuantStats layout changes, must update here

### `qs_analyze.py`
- **Main class**: `QuantStatsAnalyzer`
- **Key constant**: `TARGETS` - threshold values (CAGR 20%, MDD 20%, PF 1.5, Sharpe 1.0)
- **Output**: Badges (PASS/WARNING/FAIL), comments for each chart, summary
- **Logic**: Rule-based comparisons against TARGETS

## Coding Standards

- **Style**: PEP 8 + Black (100 char line length)
- **Tools**: Black, isort, flake8, pylint
- **Pre-commit**: Enabled - runs formatters/linters on commit
- **Type Hints**: Recommended but not enforced
- **Tests**: pytest (currently basic, should expand)

## Common Tasks

### Adding a New Analysis Rule
1. Modify `qs_analyze.py` - add logic to `QuantStatsAnalyzer.analyze()`
2. Update `TARGETS` if adding new threshold
3. Add test in `tests/test_qs_analyze.py`
4. Update docs if user-facing

### Fixing Chart Order Issues
1. Open QuantStats HTML in browser
2. Manually count chart order
3. Update `SLOT_ORDER` in `qs_extract.py`
4. Test with `--sanity-check` flag

### Adding CLI Arguments
1. Update argparse setup in `build_report.py`
2. Pass argument to relevant function
3. Add documentation in docstring
4. Update README.md usage examples

## Known Limitations

1. **12 Chart Order**: Fixed assumption - breaks if QuantStats layout changes
2. **Thresholds**: Hard-coded in TARGETS - CLI args planned for v1.1
3. **No AI Comments**: Current analysis is 100% rule-based (not LLM-generated)
4. **Single Language**: Vietnamese-only (English support planned)
5. **No Benchmark Support**: Current code assumes QuantStats with no benchmark
